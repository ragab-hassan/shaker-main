# HousingManagementWeb
نظام إدارة السكن والموظفين والعربيات — ASP.NET Core MVC / .NET 10.

## العلاقات الأساسية
- الموقع يحتوي عمارات.
- العمارة تحتوي شقق.
- الشقة تحتوي غرف.
- الموظف مرتبط مباشرة بمشروع وغرفة، ومن الغرفة يتم معرفة الشقة والعمارة والموقع.
- المشروع مرتبط بالموظفين والعربيات.
- العربية مرتبطة بالمشروع ويمكن ربطها بموظف كسائق، مع السعة وخط السير.
- حالة الغرفة تتحدث تلقائيًا حسب الموظفين النشطين المسكنين فيها.
- اختيار المنطقة في نماذج الموظفين والتعيينات المنتظرة يعرض الغرف الشاغرة التابعة لها فقط، ويُعاد التحقق من المنطقة والإشغال عند الحفظ.
- عند التسكين، يُحجز مقعد تلقائيًا في سيارة نشطة من المشروع نفسه: «هاي اس» لمنطقة مطروح أو سيدي عبدالرحمن، و«ملاكي» إذا احتوى اسم المنطقة على «مديرين». تُحسب سعة السيارة مع السائق، ولا يُنشأ حجز مكرر؛ إذا لم تتوفر سيارة أو سعة، يظهر تنبيه واضح.

## التشغيل
قبل أول تشغيل، اضبط متغير البيئة `BootstrapAdmin__Password` على كلمة مرور قوية بطول 12 محرفًا على الأقل. ينشئ التطبيق حساب `admin` بهذه الكلمة عند غياب الحساب؛ لا تُخزَّن كلمة مرور افتراضية في المستودع. على PowerShell يمكن ضبطها للجلسة الحالية هكذا:

```powershell
$env:BootstrapAdmin__Password = "ضع-كلمة-مرور-قوية-هنا"
```

إذا لم يُضبط المتغير، يعمل التطبيق دون إنشاء حساب مسؤول، ويسجل تحذيرًا يشرح المتغير المطلوب. الحساب القديم الذي يقبل كلمة مرور فارغة يُعطّل تلقائيًا، أو تُستبدل كلمة مروره بالقيمة المضبوطة.

افتح `HousingManagementWeb.csproj` في Visual Studio 2026 وشغّل المشروع. تُنشأ/تُرقّى قاعدة SQLite تلقائيًا عند بدء التشغيل.
