# HousingManagementWeb
نظام إدارة السكن والموظفين والعربيات — ASP.NET Core MVC / .NET 10.

## العلاقات الأساسية
- الموقع يحتوي عمارات.
- العمارة تحتوي شقق.
- الشقة تحتوي غرف.
- الموظف مرتبط مباشرة بمشروع وغرفة، ومن الغرفة يتم معرفة الشقة والعمارة والموقع.
- المشروع مرتبط بالموظفين والعربيات.
- العربية مرتبطة بالمشروع ويمكن ربطها بموظف كسائق، مع السعة وخط السير.
- حالة الغرفة تتحدث تلقائيًا حسب الموظفين النشطين المسكنين فيها.

## التشغيل
افتح `HousingManagementWeb.csproj` في Visual Studio 2026 وشغّل المشروع.
قاعدة SQLite موجودة/تُنشأ تلقائيًا، مع ترقية بسيطة للأعمدة الجديدة عند وجود قاعدة قديمة.
